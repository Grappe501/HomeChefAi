## Positioning hierarchy (five levels)

Market the **stack**, not a single feature. Only market what is live unless marked *future*.

| Level | Name | Status | Consumer message |
|-------|------|--------|------------------|
| **1** | **Inventory** | ✅ Live | Know what's in your kitchen. Scan receipts. Track your pantry. |
| **2** | **Kitchen Memory** | ✅ Live (Brain 1.0A) | Your kitchen remembers what you buy, cook, and waste. |
| **3** | **Kitchen Intelligence** | 🔜 Brain 1.0B | Plan meals with confidence — recommendations grounded in your history. |
| **4** | **Kitchen Growth** | 🔜 Future | Learn techniques. Master leftovers. Build your family cookbook. |
| **5** | **Kitchen Legacy** | 🔜 Future | Preserve recipes, stories, and traditions across generations. |

**Marketing rule:** Level 2 is the current flagship story. Do not sell Level 3 until Brain 1.0B ships.

## Ideal customer profiles (ICPs)

### ICP 1 — Busy Family Kitchen *(Primary · Plus $9)*

| Attribute | Detail |
|-----------|--------|
| Household | 3–6 people, dual-income or single parent |
| Pain | "What's for dinner?" nightly; food waste; no shared system |
| Motivation | Save money, reduce stress, feed family well |
| Hook | Receipt → pantry → Brain insight → "running low on milk" |
| Message | *Your kitchen already knows your patterns. SousChef helps you act on them.* |

### ICP 2 — Food Enthusiast / Growing Home Cook *(Plus → Family)*

| Attribute | Detail |
|-----------|--------|
| Profile | Cooks 4+ nights/week, wants to improve |
| Pain | Same rotation; wants technique and flavor growth |
| Motivation | Learn, impress, build identity as a cook |
| Hook | Brain habit insights, archetype detection, Clara |
| Message | *Cook with confidence. Grow from where you are.* |

### ICP 3 — Homesteader / Local Food Household *(Plus)*

| Attribute | Detail |
|-----------|--------|
| Profile | Garden, farmers market, preserve, scratch cooking |
| Pain | Seasonal inventory, waste, planning around harvest |
| Motivation | Self-sufficiency, local food, tradition |
| Hook | Local food preferences, waste tracking, pantry value |
| Message | *From garden to table — your kitchen remembers the season.* |

### ICP 4 — Retirees / Empty Nesters *(Plus or Family)*

| Attribute | Detail |
|-----------|--------|
| Profile | Cooking for two or hosting grandchildren |
| Pain | Recipe scatter; health/diet tracking; simplifying shops |
| Motivation | Health, tradition, hosting |
| Hook | Named kitchen, allergies, cook log, legacy framing |
| Message | *The kitchen you've built deserves a memory.* |

### ICP 5 — Dinner Club / Entertaining Household *(Family $18 · future)*

| Attribute | Detail |
|-----------|--------|
| Profile | Hosts clubs, holidays, parties |
| Pain | Menu coordination, dietary mix, timing |
| Motivation | Memorable experiences, community |
| Hook | Cook Together, Experience Engine *(future)* |
| Message | *Plan the evening — not just the recipe list.* |

### ICP 6 — New Cook *(Free → Plus)*

| Attribute | Detail |
|-----------|--------|
| Profile | First apartment, learning basics |
| Pain | Overwhelmed by options; doesn't know pantry state |
| Motivation | Confidence, budget, simple wins |
| Hook | Pantry wizard, Clara, onboarding priorities |
| Message | *Start with what you have. SousChef meets you there.* |

### ICP 7 — Experienced Cook *(Plus)*

| Attribute | Detail |
|-----------|--------|
| Profile | Decades of cooking, strong opinions |
| Pain | Tools treat them like beginners; no respect for skill |
| Motivation | Efficiency, precision, household coordination |
| Hook | Command-center dashboard, Brain evidence, no fluff |
| Message | *Software a serious cook would actually use.* |
